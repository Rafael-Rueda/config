# Biome and ESLint alignment

Biome and ESLint recommended presets are maintained independently, so equal preset names do not guarantee equal diagnostics. Align explicitly configured overlapping rules and avoid running duplicate formatters. A strict identical allowlist is a policy change and requires approval because it stops automatic adoption of new recommended rules.

Preserve formatter ownership and project preferences independently of lint parity. In this package, double quotes and four-space indentation are intentional.
